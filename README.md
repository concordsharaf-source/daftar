# دفتر — ملاحظات عربية لأندرويد

تطبيق ملاحظات **عربي بالكامل (RTL)** مبني بـ **Kotlin + Jetpack Compose**، بمحرر غني،
حفظ تلقائي، تراجع/إعادة، تصدير PDF، نسخ احتياطي كامل بالصور، وقفل بالرمز السري أو البصمة.

| | |
|---|---|
| الحزمة | `com.daftar.notes` |
| الإصدار | 2.6 (versionCode 6) |
| الحد الأدنى | Android 8.0 (API 26) |
| الهدف | API 35 |
| الأدوات | Kotlin 2.1.20 · AGP 8.3.2 · Gradle 8.5 · JDK 17 |

## المزايا

- **محرر غني:** عريض/مائل/تسطير، عناوين، قوائم نقطية ومرقّمة، ألوان نص، تظليل، محاذاة.
- **حفظ موثوق:** حفظ تلقائي (debounce 750ms) + حفظ فوري عند الخروج + مؤشر «تم الحفظ».
- **تراجع/إعادة:** مكدس حتى 50 لقطة، مع لقطات تلقائية أثناء الكتابة.
- **تنظيم:** تثبيت، مفضلة، ألوان وسوم، حالة (مسودة/منجزة)، سلة محذوفات.
- **بحث وترتيب:** بحث فوري في العنوان والمحتوى (الأحدث/الأقدم/أبجدي/أبجدي عربي
  بتطبيع الهمزات والتشكيل).
- **صور:** من المعرض أو الكاميرا (مع طلب الإذن وقت التشغيل) وتُحفظ في التخزين الخاص.
- **تصدير:** PDF منسّق (A4، RTL، قوائم وصور) + مشاركة نصية.
- **نسخ احتياطي:** ملف ZIP واحد (`daftar.json` + `images/`) — حفظ في مجلد أو مشاركة،
  واستعادة مع تأكيد يعرض عدد الملاحظات (وتدعم ملفات JSON القديمة).
- **أمان:** قفل بالرمز (PBKDF2-HMAC-SHA256 + Keystore، مع قفل مؤقت بعد المحاولات
  الفاشلة)، بصمة/وجه، قفل تلقائي بعد مهلة، ومنع النسخ السحابي لبيانات التطبيق.
- **مظهر:** ثيم فاتح/غامق/النظام، وخمسة خطوط عربية، وخلفية ورق مسطّرة.

## البناء والتشغيل

### عبر GitHub Actions (الأسهل)
كل push على `main` يشغّل `.github/workflows/build-apk.yml`:
يختبر، يبني APK للتصحيح وآخر للإصدار، ويرفعها كـ artifacts قابلة للتنزيل
(تبويب **Actions** ← آخر تشغيل ← Artifacts).

### محليًا
```bash
# متطلبات: JDK 17 + Android SDK 35
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

./gradlew testDebugUnitTest   # الاختبارات (21 اختبار JVM)
./gradlew assembleDebug       # APK للتصحيح
./gradlew assembleRelease     # APK للإصدار (غير موقّع)
```
مخرجات APK في `app/build/outputs/apk/`.

> ملاحظة للبيئات قليلة الذاكرة: المشروع مهيّأ لـ1GB (`gradle.properties`).
> عند 2GB RAM استخدم `-Dorg.gradle.jvmargs="-Xmx1300m" -Pkotlin.compiler.execution.strategy=in-process`.

## ملاحظات مهمة

- **قفل التطبيق يحتاج رمزًا:** عند تفعيل «قفل التطبيق» من الإعدادات يظهر حوار إنشاء
  الرمز. إطفاء القفل أو تغيير الرمز يتطلب إدخال الرمز الحالي.
- **النسخ السحابي معطّل** (`allowBackup=false` + قواعد استثناء لـ D2D) حمايةً للملاحظات؛
  استخدم «النسخ الاحتياطي» داخل التطبيق للاحتفاظ بها أو نقلها لجهاز آخر.
- **نسيت الرمز؟** لا توجد طريقة لاسترجاعه من داخل التطبيق (الرمز مخزّن كبصمة مشتقة
  فقط)؛ لكن الملاحظات تبقى على الجهاز وقابلة للاستعادة عبر نسخة احتياطية سابقة.

## نسخة الويب (PWA) — جديدة

بجانب تطبيق أندرويد، أصبح لـ«دفتر» **نسخة ويب كاملة الوظائف** في مجلد `docs/`:

- تعمل **بلا اتصال** وتُثبَّت على الجهاز كتطبيق (PWA).
- نفس الهوية البصرية (حبر + رقّ)، ونفس الخطوط العربية الخمسة.
- نفس صيغة البيانات، وملفات النسخ الاحتياطي **متبادلة مع تطبيق أندرويد** في الاتجاهين.
- بياناتك تبقى على جهازك في IndexedDB — لا سيرفر ولا حساب.
- **قفل التطبيق**: باترن أو رمز سري أو بصمة الجهاز، مع **تشفير حقيقي** لنص الملاحظات
  (AES-GCM + PBKDF2) وقفل تلقائي عند مغادرة التطبيق.
- **عدّاد الكلمات والأحرف** أسفل الملاحظة، وأزرار تحكم أكبر مع زر ✕ يُلغي كل التأثيرات
  حتى على النص الذي ستكتبه.
- **استيراد من Google Keep**: اختر ملف `Takeout.zip` فتُنقل الملاحظات بعناوينها ونصوصها
  وقوائم مهامها وألوانها وتثبيتها، والمحذوف يدخل السلة — بلا أي حذف لما عندك.
- **قفل ملاحظة واحدة** وقفل مجموعة: تُخفى المقفلة عن القائمة والبحث حتى تُفتح بالباترن/الرمز،
  و**تحديد عدة ملاحظات** لتنفيذ عمليات جماعية (تثبيت، مفضلة، لون، قفل، حذف، استعادة).
- إلغاء القفل وتغيير الباترن/الرمز من الإعدادات، وزر الرجوع يعود للقائمة بدل الخروج من التطبيق.
